### ╰┈➤ ✦ Regras

O multiplicador da mensalidade varia conforme a idade informada:

| Faixa Etária | Multiplicador |
| :--- | :---: |
| `0` a `18` anos | `1.0x` *(Valor base)* |
| `19` a `28` anos | `1.5x` |
| `29` a `38` anos | `2.25x` |
| `39` a `48` anos | `2.4x` |
| `49` a `58` anos | `3.5x` |
| `59` anos ou mais | `6.0x` |
